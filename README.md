# Khoa Nguyen's Personal Website

My developer portfolio, 2025 version. Check it out at: [khoa-ng.vercel.app](https://khoa-ng.vercel.app/)!

## Features

- The website is fully responsive.
- Transition animations.
- SSR with NextJS.

## Stack

- [Next.js](https://nextjs.org/) - A React framework for the web.
- [Aceternity UI](https://ui.aceternity.com/) - A UI library for NextJS.
- [Framer Motion](https://www.framer.com/motion/) - A production-ready motion library for React.
